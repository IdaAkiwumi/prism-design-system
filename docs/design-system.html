Motion & accessibility tokens
WCAG AA contrast and reduced motion support
Motion
  • --motion-duration-fast → used for buttons and toggles (200ms).
  • --motion-duration-moderate → used for modals, drawers, and page transitions (300ms).
  • All animated components include @media (prefers-reduced-motion: reduce) { transition: none; }.
Accessibility
  • Text on any background targets at least a 4.5:1 contrast ratio (WCAG AA).
  • Focus states are always visible and never rely on outline: none.
  • Theme switching preserves contrast by redefining semantic tokens, not component styles.

Theme switching behavior
// 1. Update data-theme on <html>
document.documentElement.setAttribute('data-theme', theme);

// 2. Redefine CSS variables with theme hex values
document.documentElement.style.setProperty('--color-action-primary', hex);
document.documentElement.style.setProperty('--color-surface-default', hex);
document.documentElement.style.setProperty('--color-text-primary', hex);
document.documentElement.style.setProperty('--color-surface-raised', hex);

// 3. Update derived tokens like --color-button-text
// so components update instantly.
PRISM AI agent rules
Design-time constraints baked into the system

Token rules

  • Never hardcode hex values in components; always use semantic tokens like var(--color-action-primary).
  • Always reference semantic tokens, not primitive color values, in component styles.
  • Read each token description before applying it to confirm intent.

Theme rules

  • Apply themes via the data-theme attribute on the root <html> element.
  • Never duplicate or fork components for different themes; only override semantic tokens.
  • Use the exact theme values: Base Entertainment Education

Agentic UI patterns

  • Intent preview uses card + badge components together.
  • Confidence badge colors:
    • High → --color-feedback-success
    • Medium → --color-feedback-warning
    • Low → --color-feedback-danger
  • Escalation flows must show a visible human handoff option.

Accessibility & motion

  • Text on any background targets a minimum 4.5:1 contrast ratio (WCAG AA).
  • Focus states are always visible and never rely on outline: none.
  • All animated components include a prefers-reduced-motion override.
