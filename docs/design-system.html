PRISM Design System

Tokens, components, themes, and AI agentic patterns in a single reference page.

Semantic tokens

Use semantic tokens instead of raw hex values. Themes redefine these tokens without changing component code.

Action & feedback

  • --color-action-primary → primary CTAs, focused elements
  • --color-feedback-success → success toasts, badges
  • --color-feedback-warning → cautionary states
  • --color-feedback-danger → errors, critical alerts

Surfaces & text

  • --color-surface-default → app background
  • --color-surface-raised → cards, modals, dropdowns
  • --color-text-primary → body text on light surfaces
  • --color-text-inverse → text on colored/dark surfaces

CSS token setup

/* Base theme (default) */
:root {
  --color-action-primary: #0066CC;
  --color-surface-default: #FFFFFF;
  --color-text-primary: #111111;
  --color-surface-raised: #F5F5F5;
  --color-text-inverse: #FFFFFF;
}

/* Components consume semantic tokens */
.btn-primary {
  background: var(--color-action-primary);
  color: var(--color-text-inverse);
}

Button

Primary, secondary, and ghost variants. Primary uses --color-action-primary and respects theme-specific text rules.

Preview

Focus states use a 2px outline with --color-action-primary and 2px offset.

Code snippet

.btn {
  padding: 8px 16px;
  border-radius: var(--border-radius-default);
  border: 1px solid transparent;
  cursor: pointer;
}

.btn-primary {
  background: var(--color-action-primary); /* semantic: primary CTA */
  color: var(--color-text-inverse);       /* semantic: inverse text */
}

/* Education theme override for contrast rule */
[data-theme="education"] .btn-primary {
  color: #111111;
}

Token mapping

  • Background: var(--color-action-primary)
  • Text (Base/Ent): var(--color-text-inverse)
  • Text (Education): #111111 override
  • Border radius: var(--border-radius-default)
  • Focus outline: var(--color-action-primary)

Pattern rules

  • High confidence: badge uses --color-feedback-success
  • Medium confidence: badge uses --color-feedback-warning
  • Low confidence: badge uses --color-feedback-danger
  • Medium: offer “Approve” and “Edit” actions
  • Low: also show “Talk to a person” and explain why confidence is low
