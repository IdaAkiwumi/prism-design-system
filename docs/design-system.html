CSS variable definition

Variables are always defined as --token-name: value; and updated on theme change.

:root {
  --color-action-primary: #0066CC; /* base */
  --color-surface-default: #FFFFFF;
  --color-text-primary: #111111;
  --color-surface-raised: #F5F5F5;
  --color-text-inverse: #FFFFFF;
}

Theme switch behavior

The dropdown updates <html data-theme="…"> and redefines all CSS variables with the exact hex values. 

function applyTheme(theme) {
  const root = document.documentElement;
  root.dataset.theme = theme;

  if (theme === 'base') {
    root.style.setProperty('--color-action-primary', '#0066CC');
    root.style.setProperty('--color-surface-default', '#FFFFFF');
    root.style.setProperty('--color-text-primary', '#111111');
    root.style.setProperty('--color-surface-raised', '#F5F5F5');
    root.style.setProperty('--color-text-inverse', '#FFFFFF');
  }
  // entertainment / education branches omitted for brevity
}

Theme swatches (hardcoded)

These buttons intentionally use hardcoded hex backgrounds and do not rely on CSS variables.

Primary button text rules

  • Base & Entertainment → text uses var(--color-text-inverse) (white).
  • Education → text explicitly overridden to #111111 for contrast.

AI + design rules

  • Use semantic tokens (e.g., --color-action-primary) instead of raw primitives.
  • All animated components must respect @media (prefers-reduced-motion: reduce).
  • Apply themes via data-theme on the <html> element.
  • Never fork components per theme—only override semantic tokens.
  • Maintain at least 4.5:1 contrast for text on any background.
  • Focus states must always be visible; never rely on outline: none alone.
